**AI QA Assistant** — расширение для Chrome, автоматизирующее тестирование веб-приложений с помощью семантического анализа текста.

### Архитектура проекта

Проект состоит из следующих компонентов:

* **Background Service Worker** — управляет ИИ-моделью и коммуникацией между компонентами
* **Side Panel** — пользовательский интерфейс для ввода тестовых сценариев
* **Content Script** — взаимодействует с DOM тестируемой страницы
* **AI Engine** — обработка естественного языка и семантический поиск

### Установка

1. Скачайте все файлы проекта
2. В Chrome перейдите в `chrome://extensions/`
3. Включите режим разработчика
4. Нажмите "Загрузить распакованное расширение"
5. Выберите папку с проектом

### Использование

1. Откройте тестируемый сайт
2. Активируйте расширение через иконку в панели расширений
3. В боковой панели введите тестовый сценарий
4. Нажмите кнопку "Запустить"

### Пример сценария

```
1. Нажать кнопку "Войти"
2. Ввести логин "testuser"
3. Нажать "Отправить"
4. Результат: Появилось приветствие "Добро пожаловать!"
```

### Технические требования

* Chrome версии 90+
* Не менее 2 ГБ свободной памяти
* Подключение к интернету для загрузки модели

### Известные ограничения

* Требуется время на инициализацию модели
* Работает только в Chrome
* Некоторые сложные сценарии могут требовать доработки

### Поддержка русского языка

Расширение использует мультиязычную модель, которая поддерживает:
* Русский язык
* Английский язык
* Автоматическое определение языка ввода
* Работу с смешанным контентом
