# 🤖 AI QA Assistant

Расширение для Chrome, которое запускает тестовые сценарии на реальной веб-странице, описанные обычным текстом на русском или английском. Без Selenium, без Playwright, без облака — всё работает в самом браузере.

```
Нажми кнопку "Авторизоваться"
Введи в поле "Имя пользователя" текст "testuser"
Нажми Enter
Результат: Добро пожаловать, testuser
```

**Текущая версия: 0.2** — детерминированное ядро + управление вкладками. Семантическая модель пока не подключена: резолвер цели работает на точных совпадениях, префиксах и Jaccard по токенам.

## Возможности

### Действия над страницей

| Действие | Что делает | Пример |
|---|---|---|
| **Клик** | Левый клик по элементу | `Нажми кнопку "Отправить"` |
| **Правый клик** | Полная эмуляция pointer + mouse + `contextmenu` | `Правый клик по "Избранное"` |
| **Ввод** | Запись в `<input>`, `<textarea>`, `[contenteditable]` | `Введи в поле "Email" текст "test@test.ru"` |
| **Выбор** | Выбор опции в `<select>` | `Выбери "Москва"` |
| **Нажатие клавиши** | Enter, Tab, Escape, стрелки, F1–F12, буквы, комбинации | `Нажми Ctrl+Enter` |
| **Скролл** | Прокрутка окна или элемента | `Прокрути вниз на 500` |
| **Пауза** | Ожидание с обратным отсчётом | `Подожди 3 секунды` |
| **Проверка** | 12 видов структурных и текстовых проверок | `Проверь, что URL содержит "/chat"` |

### Управление вкладками

| Действие | Что делает | Пример |
|---|---|---|
| **Список вкладок** | Показать все вкладки текущего окна | `Список вкладок` |
| **Переключение** | Активировать вкладку по title/URL | `Переключись на вкладку "DeepSeek"` |
| **Открытие** | Новая вкладка с URL, дождаться загрузки | `Открой вкладку "https://example.com"` |
| **Закрытие** | Закрыть текущую или указанную вкладку | `Закрой текущую вкладку` |
| **Обновление** | Перезагрузить страницу | `Обнови страницу` |
| **Назад / Вперёд** | История навигации | `Вернись назад` |
| **Соседняя вкладка** | Циклическое переключение | `Следующая вкладка` |

### Ожидаемый результат

Строка `Результат: …` (а также `Ожидаемый результат:`, `Result:`, `Then:`) привязывается к предыдущему действию и автоматически проверяется после него.

### Подсветка

Найденный элемент подсвечивается фиолетовым контуром. Через 2 секунды подсветка плавно затухает за 500 мс.

## Установка

1. Скачайте файлы расширения в отдельную папку.
2. Откройте `chrome://extensions/`.
3. Включите **Режим разработчика**.
4. Нажмите **Загрузить распакованное расширение**.
5. Выберите папку с расширением.

**Требования:**
- Chrome **114+**
- Никаких внешних подключений

## Быстрый старт

1. Откройте любую страницу.
2. Кликните иконку расширения → откроется боковая панель.
3. Введите сценарий.
4. Нажмите **▶ Запустить**.

### Общие правила

- **Один шаг — одна строка.**
- Нумерация в начале строки игнорируется: `1. Нажми Enter` = `Нажми Enter`.
- Русский и английский равноправны. Регистр не важен.
- Кавычки: `"…"`, `'…'`, `«…»`, `“…”` — любые.
- Пустые строки пропускаются.

## Как работает резолвер

Каждая цель сопоставляется со всеми интерактивными элементами. Оценка — по каскаду:

| Условие | Score |
|---|---|
| Точное совпадение | 1.00 |
| Текст начинается с цели | 0.95 |
| Текст содержит цель | 0.90 |
| Цель содержит текст элемента (≥3 симв.) | 0.75 |
| Jaccard по токенам × 0.85 | до 0.85 |
| Элемент перекрыт другим | ×0.7 |

**Порог:** 0.55. **Неоднозначность:** разница между первым и вторым < 0.05 при score < 0.9 — остановка с показом кандидатов.

### Что попадает в подпись

`aria-label`, `label[for]`, wrapping `<label>`, `placeholder`, `data-placeholder`, `aria-placeholder`, `title`, `alt`, видимый текст. Всё нормализуется: нижний регистр, схлопнутые пробелы, кавычки убраны.

### Какие элементы видит резолвер

`button`, `a[href]`, `input` (кроме hidden), `textarea`, `select`, `[role=button|link|textbox|combobox|menuitem|menuitemcheckbox|menuitemradio|option|tab]`, `[contenteditable]`.

Отсеиваются: невидимые, без текста, `disabled` при выполнении.

## Как работает ввод в rich-редакторы

Telegram, DeepSeek и другие SPA используют contenteditable на Lexical / ProseMirror / Slate. Эти редакторы хранят текст в модели и рендерят эмодзи как пустые декораторы.

Расширение:

1. Выделяет текущее содержимое.
2. Отправляет синтетическое `beforeinput`.
3. Если через 120 мс текста нет — отправляет синтетическое `paste` с `DataTransfer`.
4. Читает `textContent`, проверяет: probe (первые 15 символов значения без эмодзи) должен найтись **ровно один раз**.
5. Обе стороны сравнения проходят через `stripEmoji`, поэтому декораторные эмодзи не мешают.

## Архитектура

```
┌─────────────────┐       ┌──────────────────┐       ┌──────────────────┐
│   Side panel    │──────▶│   Background     │──────▶│  Content script  │
│ (парсер, UI,    │       │ (релей, инъекция │       │ (резолвер DOM,   │
│  оркестратор,   │◀──────│  content script, │◀──────│  действия, чеки) │
│  tabs API)      │       │  tabs API)       │       │                  │
└─────────────────┘       └──────────────────┘       └──────────────────┘
```

**Side panel** — интерфейс, парсер, раннер шагов, `currentTabId`.

**Background** — релей между панелью и вкладками. Обрабатывает `TAB_CALL` (проксирует к content script) и `TABS_CALL` (операции с вкладками через `chrome.tabs`). Инжектит content script в уже открытые вкладки.

**Content script** — всё про DOM: `DESCRIBE`, `PERFORM`, `SCROLL`, `CHECK_ELEMENT`, `HIGHLIGHT`, `SNAPSHOT`, `WAIT_STABLE`.

**manifest.json** — MV3, разрешения `sidePanel`, `scripting`, `tabs`, `host_permissions: <all_urls>`.

## Транспорт и надёжность

- **Fallback-инъекция.** Если content script не загружен (расширение перезагружено, вкладка была открыта раньше) — background инжектит его автоматически.
- **Запрет на служебные страницы.** На `chrome://`, `edge://`, `about:` — внятная ошибка.
- **Ожидание стабилизации DOM.** `MutationObserver` с окном тишины 250 мс и жёстким потолком 4 с. Для навигации — до 8–10 с.
- **Отмена.** Кнопка **Отмена** прерывает прогон между шагами и во время пауз.
- **Сверка фактического значения.** После `input` читается значение обратно. React-сброс обнаруживается.
- **Защита от закрытия последней вкладки.** Иначе Chrome закроет окно вместе с панелью.

## Известные ограничения

- **Нет iframe.** Элементы внутри вложенных фреймов невидимы.
- **Нет shadow DOM.**
- **Нет hover, drag&drop, загрузки файлов.**
- **Кастомные селекты (React-Select, MUI) не выбирают опцию** — только открываются.
- **`Проверь, что текст есть` ищет по всему `body`.** Не отличает текст, который был до действия, от появившегося после.
- **Управление вкладками работает только в текущем окне.** Переключение на вкладку в другом окне не поддерживается (панель осталась бы в старом окне).
- **Синтетический Enter не вставит перевод строки в пустую `<textarea>`** без обработчика. В чатах и формах, где на Enter висит отправка, работает.
- **Скролл работает с окном и обычным overflow.** Виртуальные списки требуют прямого `scrollTop`.
- **Только Chrome 114+.**
- **Нет скриншотов и экспорта отчёта.**
